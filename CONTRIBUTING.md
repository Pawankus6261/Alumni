# Contributing

Thanks for helping improve BGI Alumento.

## Development setup

1. Install Node.js 20 and npm.
2. Install dependencies with `npm ci`.
3. Start the app with `npm run dev`.

## Before opening a pull request

- Keep changes focused and preserve the existing React/Vite structure.
- Check the affected pages at desktop and mobile widths.
- Run `npm run build` and resolve build errors.
- Describe the user-visible change and any known limitations in the pull request.

Please do not commit `node_modules/`, `dist/`, local `.env` files, or credentials.
